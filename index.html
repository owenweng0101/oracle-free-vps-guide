大流量，不等于保证高速。

50Mbps 是 E2 Micro 的官方公网带宽上限，不是你家网络到它的保底速度，也不是每个设备独享。地区、运营商、晚高峰和同时使用人数都会影响体验。

  • 免费 ≠ 免配置需要申请、保管密钥、配置网络和代理服务。
  • 免费 ≠ 所有产品都免费只选额度内的免费资源，不要顺手创建付费实例、网关或其他产品。
  • 免费 ≠ 永不回收长期闲置的计算资源可能回收，不能把它当作唯一连接保障。

从注册，到拿到一台服务器。

不需要先买域名。先准备好自己的资料，再认真选择主区域。

准备注册资料

本人真实有效的资料、可接收验证的邮箱和手机号，以及平台接受的信用卡或具备相应功能的借记卡。可能有临时验证预授权；是否通过审核由 Oracle 决定。

在官网创建免费账号

进入 Oracle Cloud Free Tier 注册页 ↗，完成验证。每人只允许一个免费账号，不能通过换邮箱反复注册。

谨慎选择主区域

圣何塞、东京、大阪、新加坡等以实际注册列表为准。主区域注册后不能更改，Always Free 计算资源只能建在主区域。没有一个地区能保证库存或对所有网络都更快。

创建免费计算实例

在主区域进入 Compute → Instances → Create instance，选择免费兼容的 Linux 镜像与 VM.Standard.E2.1.Micro 或额度内的 VM.Standard.A1.Flex，核对存储总量。

配好网络与登录方式

创建或选择公网子网，核对互联网网关和默认路由，分配公网 IPv4。保存 SSH 私钥，只放行管理与实际服务需要的端口。IPv6 是可选的额外连接路径。

等实例运行，先验证 SSH

确认实例为 Running，再用密钥登录 Linux。若返回 Out of capacity，表示免费规格暂时缺货，可稍后重试，不能把“注册成功”当成“机器已到手”。

与另外三个入口共用服务器及流量

手机可用兼容客户端，例如 Shadowrocket；Mac、Windows 可用 Clash Verge Rev 等。部分客户端可能另收费，客户端费用与服务器免费额度是两回事。

部署顺序很重要

  1. 按软件官方文档安装服务，创建自己的强凭证。
  2. 配置 TLS / 证书验证，放行服务端口，设置开机启动。
  3. 生成客户端参数、链接或二维码，保管好 SSH 密钥和备份。
  4. 分别测试连接、网页、App 和持续视频；成功后再考虑其他入口。

HY2、SS 是代理协议，IPv4、IPv6 是服务器地址类型。拆更多二维码主要方便管理，不意味着更抗封或增加流量额度。

朋友通常会问的几个问题

能免费用一年吗？

Always Free 没有预设的一年到期日，可以持续使用，但须符合账号、额度和服务规则；这不是对一年不间断运行的承诺。官方说明

每个月是100TB，还是10TB？

是每月前10TB公网出站流量免费。观看视频时，服务器转发给设备的数据属于出站。不是每台设备、每个二维码各有10TB，也不是无限流量。

每天登录一下，就不会被回收吗？

不能这么保证。Oracle 根据连续7天的CPU、网络等使用指标判断计算资源是否闲置；A1还涉及内存指标。账号长期闲置也另有规则。保留配置和数据备份。闲置规则

重启服务器，IP会变吗？

Oracle 官方说明，正常重启、停止后再启动同一实例会保留临时公网IP。主动释放IP、删除对应实例或网卡后重建，则不能指望保留原地址。地址变化后，写死IP的二维码与本地配置需要更新。IP生命周期

日本、新加坡一定比美国快吗？

不能仅凭地理位置下结论。你的运营商、线路与时段更关键，注册列表也不显示免费机器实时库存。这里不提供“哪个区一定最快、一定有货”的排名。

除了上网，这台VPS还能干什么？

还可以学习Linux、部署网站和个人工具。它是一台完整的虚拟服务器，上网代理是装在上面的用途。额外服务仍需考虑资源、流量、维护和平台条款。
